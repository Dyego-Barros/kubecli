Instruções do KubeCLI

Como funciona

O KubeCLI reúne os comandos Kubernetes, OpenShift, cloud e gerenciamento de ferramentas em um único terminal. Os prefixos são opcionais no app.

Comandos Kubernetes

k get podsAtalho para kubectl get pods get pods -AExecuta kubectl get pods -A podsLista pods no namespace atual svcLista services deployLista deployments nodesLista nodes do cluster eventsLista eventos ordenados por data logs PODExibe logs de um pod describe pod/PODDetalha um recurso kubectl COMANDOPassa qualquer comando diretamente ao kubectl

Contexto e namespace

ctxLista contextos ctx listLista contextos explicitamente ctx use NOMETroca o contexto Kubernetes xAtalho para listar contextos nsLista namespaces ns listLista namespaces explicitamente ns use NOMETroca o namespace atual n NOMEAtalho para trocar namespace

CLIs Kubernetes

kubectl ARGSExecuta kubectl com os argumentos informados kubens ARGSExecuta kubens kubectx ARGSExecuta kubectx oc ARGSExecuta o OpenShift CLI oc get projectsExemplo de comando OpenShift

Instalação e ferramentas

install kubectlInstala kubectl pelo gerenciador detectado install kubensInstala kubens install kubectxInstala kubectx install ocInstala OpenShift CLI install awscliInstala AWS CLI install azurecliInstala Azure CLI install googlecliInstala Google Cloud CLI uninstall NOMERemove uma ferramenta com confirmação listMostra sistema, gerenciador e versões setupVerifica e instala ferramentas ausentes

Aliases

aliasesLista aliases disponíveis aliases listLista aliases explicitamente aliases add NOME kubectl get podsCria alias personalizado aliases remove NOMERemove alias personalizado

Aliases personalizados ficam em ~/.config/kubecli/aliases.json.

Cloud

cloud login azurecliExecuta az login cloud configure awscliExecuta aws configure cloud login googlecliExecuta gcloud auth login cloud status awscliMostra identidade AWS atual cloud status azurecliMostra conta Azure atual cloud status googlecliLista contas Google autenticadas

Kubeconfig

kubeconfig addAdiciona cluster interativamente kubeconfig remove NOMERemove cluster e contexto associado

O app começa com ~/.kube/config. Use Escolher kubeconfig para selecionar outro arquivo e Editar kubeconfig para abri-lo.
