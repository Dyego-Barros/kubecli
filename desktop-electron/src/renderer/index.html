Instruções do K8sOps

Como funciona

O K8sOps reúne Kubernetes, OpenShift, cloud, agentes e MCP em um único terminal. Os aliases padrão são mínimos e usam o prefixo k.

Comandos Kubernetes

k get podsAtalho para kubectl get pods k COMANDOExecuta kubectl COMANDO kubectl COMANDOPassa qualquer comando diretamente ao kubectl

O único alias Kubernetes padrão é k. Crie atalhos adicionais com aliases add.

Contexto e namespace

kctxLista contextos kctx listLista contextos explicitamente kctx use NOMETroca o contexto Kubernetes knsLista namespaces kns listLista namespaces explicitamente kns use NOMETroca o namespace atual

Os comandos completos kubecli ctx e kubecli ns também continuam disponíveis.

Outros atalhos devem ser criados pelo usuário com aliases add.

Inteligência artificial e MCP

Use o alias ai no terminal para os comandos de agentes e MCP. O agente é definido por um arquivo AGENTS.md; o MCP conecta ferramentas externas ao K8sOps.

Agentes

ai agents [DIRETÓRIO]Lista arquivos AGENTS.md encontrados ai start --agent /caminho/AGENTS.mdInicia a sessão com o arquivo escolhido ai ask "PROBLEMA"Envia uma solicitação ao agente atual ai historyMostra agente, contexto, modelos e última resposta

Fluxo: primeiro liste os arquivos com ai agents, escolha um caminho real e passe esse caminho para ai start --agent.

MCP

ai mcp listLista os servidores MCP cadastrados ai mcp testDescobre as tools de todos os MCPs habilitados ai mcp test NOMEDescobre as tools de um MCP específico ai mcp call SERVIDOR TOOL --arguments '{}'Chama uma tool e mostra o retorno bruto ai mcp ask SERVIDOR TOOL --arguments '{}'Chama a tool e pede à LLM para formatar o retorno

stdio: o K8sOps inicia o servidor MCP configurado em Comando e Argumentos.

sse: o servidor já está rodando e o K8sOps conecta à URL SSE.

streamable_http: o servidor já está rodando e o K8sOps conecta à URL HTTP streamable, normalmente terminada em /mcp.

Em stdio, Comando contém somente o executável e Argumentos contém os parâmetros. Em HTTP, deixe Comando e Argumentos vazios e informe apenas a URL.

ai modelsLista os modelos de IA configurados ai listAlias de ai models

No desktop, use o menu IA para escolher o agente, configurar modelos e APIs ou configurar servidores MCP.
